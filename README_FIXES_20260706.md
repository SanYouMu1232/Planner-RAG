# Planner V8 修复版说明

本版基于你重新发送的 Planner V8 前端，继续保留原 UI 设计，只修复前后端联动和交互问题。

## 本次修复

1. 工作台对话页删除“需要进一步确认的问题”栏。
2. 对话回答不再使用默认演示文案；切走再切回时会从后端 conversation/message 读取真实 answer 和 citations。
3. 知识库“查看摘要”改为打开摘要抽屉，不再打开原文抽屉。
4. 标签支持增删改查：
   - 点击标签进入管理状态；
   - 可改名；
   - 可删除；
   - 可新增标签到已选资料，未选资料时应用到当前知识库列表资料；
   - 后端通过 document PATCH 同步 tags。
5. 知识库表格优化：
   - 删除“所属知识库”列；
   - 固定列宽；
   - 禁止横向拖动；
   - 增加表格区域竖向滚动；
   - 列内容超长截断，不挤占其他列。
6. 上传资料增加同名文件审查；同名时弹窗提示，用户确认后才继续上传。
7. 项目库支持改名；项目卡片右上角点击铅笔即可改名，后端走 PATCH /api/projects/{id}。
8. 顶部项目标签调整为浏览器标签样式：同等大小，未激活标签更清楚。
9. API 配置页小眼睛交互修正：睁眼显示明文，闭眼显示圆点。

## 校验

- 前端 `npm run build` 已通过。
- 后端 `pytest` 已通过，45 个测试通过。
